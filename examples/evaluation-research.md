# Five-query public research check

Role: [OpenAI Software Engineer, Core Services, San Francisco](https://openai.com/careers/software-engineer-core-services-san-francisco/).

This is a source-evidence comparison for compensation/company research (Blocks D
and G), not a complete CV-based Career Ops evaluation or a provider benchmark.
The baseline was supplied by the issue author from native web searches on
November 2, 2026, with the role page separately fetched. It was not a Career Ops
run; its raw responses are unavailable here. The Parallel column comes from the
plugin's actual read-only research output on November 3, 2026, using exactly the
five queries in `public-queries.json`, one search call per query and no page fetches.
Different collection times and incomplete baseline evidence prevent a controlled
quality or speed claim.

Run from Career Ops after installation and enablement:

```bash
node plugins.local/parallel/research.mjs . plugins.local/parallel/examples/public-queries.json
```

apples-to-apples market ranking. For Block G, neither verifies a specific recruiter

evidence on every question. Keep explicit unknowns and source provenance in the
evaluation, and verify current official pages before acting. No personal candidate
files were used and no report, score or tracker entry was generated by this check.
